# 숨결 (Sumgyeol)

내 프록시로 휴대폰 전체를 연결하는 안드로이드 앱.
PC판과 같은 터널 방식, SOCKS5 프록시 지원.

## 📲 APK 받는 법 (GitHub가 자동으로 빌드)

1. 이 폴더 전체를 본인 GitHub 저장소에 올린다 (public 또는 private)
2. 저장소 상단 **Actions** 탭 → 왼쪽 **Build APK** → **Run workflow** (또는 그냥 올리면 자동 실행)
3. 초록색 체크가 뜨면 (약 5~10분) 그 실행 결과 페이지 맨 아래 **Artifacts → 숨결-apk** 다운로드
4. 압축 풀면 `숨결.apk` → 휴대폰으로 옮겨 설치 (출처를 알 수 없는 앱 허용)

## 📖 사용법

1. 앱 열기
2. PC에서 쓰던 프록시를 한 줄 붙여넣기 칸에 넣고 [풀기] (예: `1.2.3.4:8080:아이디:비번`)
   또는 종류/서버/포트/아이디/비번 직접 입력
3. [연결하기] → "VPN 허용" 확인
4. 상태가 "● 연결됨"이 되면 성공

## ⚙️ 참고

- **SOCKS5 권장**: 모바일 터널 엔진은 SOCKS5를 완전 지원합니다. HTTP도 되지만 일부 제한될 수 있어요.
- **끊기면 인터넷 차단(킬스위치)**: 설정 → 네트워크 → VPN → 숨결 → "항상 연결 VPN" + "연결 없이 차단" 켜기
- **빠른 설정 타일**: 알림창 타일 편집에서 "숨결"을 추가하면 한 번에 켜고 끌 수 있어요
